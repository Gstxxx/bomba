# 💣 BOMB

Jogo da bomba: descubra o código de 4 dígitos antes que ela exploda.

- ⏱️ **1 minuto** no relógio, tentativas ilimitadas
- 🔢 **Fácil**: dígitos 1–4 (256 combinações) · **Difícil**: dígitos 0–9 (10.000)
- 🔊 Beep em cada clique, tique que acelera no fim, explosão e tela final
- 📒 Caderninho com as tentativas e a tabela 1111 → 4444 pra não se perder
- 🤖 Robô que testa tudo em ordem (1111 → 4444) e sempre ganha no Fácil

**Jogue:** https://gstxxx.github.io/bomba/

Feito só com HTML, CSS e JavaScript, sem dependências externas. As fontes (DSEG e fontes OFL via Fontsource) ficam em `assets/fonts/`, com as licenças.
